# Phantoms in Derived Categories of Surfaces

This repository accompanies the paper *A Looming of Phantoms*, which investigates the appearance of phantom categories in the derived categories of certain algebraic surfaces. The included SageMath script, `phantoms.sage`, provides computational support for identifying and studying these structures.

## Contents

- `phantoms.ipynb`: SageMath jupyter notebook with symbolic computations for computing dimensions of linear systems on the projective plane or on the Hirzebruch surface $\mathbb F_2$
- `phantoms.sage`: SageMath script version of the above.

## Requirements

- [SageMath](https://www.sagemath.org/) version 9.0 or higher

## Usage

To run the script, use:

```bash
sage phantoms.sage
```
